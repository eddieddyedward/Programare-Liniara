# Rezolvarea problemelor de programare liniară

Acest proiect implementează algoritmul Simplex și metoda Big M pentru rezolvarea problemelor de programare liniară din cadrul Cercetarilor Operaționale.

## Funcționalități

- probleme de maximizare și minimizare;
- restricții <=, = și >=;
- variabile fără restricție de semn;
- standardizarea automată a problemei;
- metoda Big M;
- detectarea problemelor fără soluție;
- detectarea problemelor nemărginite.

## Tehnologii

- Python
- NumPy

## Rulare

```bash
python src/main.py
